# Lumeria · Noor's October report — prototype

A tap-through iPhone prototype of the redesigned monthly skin report, built from the final flow screens.

- Open `index.html` (or the Vercel URL) on a phone. It scales to the screen width.
- The **Screens** pill at the top jumps to each way in (notification, Home, after a scan, loading, error) or starts over.
- Scan photos are the take-home's mock images. Noor's real scope photos are private and are not in this repo.
